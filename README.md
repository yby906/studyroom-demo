# 静园 · 校园自习室预约管理系统

面向《校园自习室预约管理系统软件需求规格说明书》的本地可运行实现。使用 **原生 HTML / CSS / JavaScript** 编写，**无需数据库、无需后端接口、无需 npm install、无需构建**；双击启动脚本即可在本机浏览器中使用。

> 本版本定位为需求规格说明书的配套演示系统：用浏览器 `localStorage` 持久化业务数据，并内置 30 天示例预约、违约与黑名单数据，便于演示全部业务流程。不是生产级多用户系统。

---

## 一、快速开始

### 环境要求

- Windows 10 / 11、macOS 或 Linux
- Node.js 18 或更高版本（仅用于启动一个零依赖静态文件服务器）
- 现代浏览器：Edge、Chrome、Firefox、Safari

### 启动方式

**方式一：双击启动（Windows）**

双击 `start.cmd`，浏览器会自动打开 <http://127.0.0.1:5173/>。关闭命令行窗口即停止服务。

**方式二：命令行**

```powershell
cd 本文件夹
node server.js
```

默认端口 `5173`；如被占用会自动顺延到 `5174`、`5175` 等，控制台会打印实际地址。可通过环境变量指定：

```powershell
$env:PORT=8080; node server.js
```

也可以使用任意静态文件服务器托管本目录，例如：

```powershell
npx serve .
# 或 python -m http.server 8080
```

> 请勿直接双击 `index.html` 用 `file://` 打开：项目使用原生 ES Modules，浏览器在 `file://` 下会阻止模块加载。

| 自习室管理员 | `roomadmin` | 王岚 | 房间维护、座位维护、全校预约查询、违约与黑名单、报表导出 |

登录页提供四个角色的一键体验入口。系统还预置了 `student3`–`student16` 等学生账号，便于在管理员端查看多人预约与违约数据。

### 自助注册

登录页点击“注册新用户”，填写姓名、登录名、密码、确认密码、学号（选填）和院系（选填）即可创建学生账号。注册成功后自动登录；账号与密码保存在当前浏览器的 `localStorage` 中，下次可在登录页直接登录，系统管理员也能在“账号权限”中看到并管理该账号。

> 注册账号固定为学生角色；登录名不可重复。由于是本地演示，密码以明文保存在浏览器本地，请勿使用真实校园密码。

### 数据备份与恢复

左侧栏“数据备份”对所有角色开放。点击后可：

- **导出 JSON 备份**：把当前浏览器中的账号、预约、座位、违约、日志、配置和时间等完整数据下载为一个 JSON 文件；
- **导入 JSON 备份**：选择之前导出的文件，确认后覆盖当前数据并回到登录页，使用备份中的账号重新登录。

导入前会显示备份中的账号、预约、日志等数量并要求二次确认。备份文件包含账号密码等敏感信息，请勿公开发送。该功能用于备份、换机迁移和答辩前存档，不会把数据共享给其他浏览器或设备。

## 三、功能对照（需求规格说明书）

### 公共用例

- 账号密码登录；学生 / 自习室管理员 / 图书馆负责人 / 系统管理员四类角色。
- 登录页支持新用户自助注册：默认学生角色，姓名、登录名、密码、学号与院系保存在本地，注册成功后自动登录。
- 连续认证失败达到阈值后锁定账号（默认 5 次 / 15 分钟），登录成功与失败均写入日志。
- 会话超时（默认 30 分钟）后自动回到登录页；登录状态保存在本地。

### 学生操作模块

- **查询自习室及空闲座位**：按日期（可预约今天起 7 天）、自习室、开始/结束时间筛选；座位图区分空闲、已预约、使用中、本人预约、维修停用，每 30 秒自动刷新。
- **预约座位**：按 30 分钟粒度选择时段；校验开放时间、可提前天数、时长、黑名单、本人时段冲突、座位实时冲突，并展示预约编号与签到截止时间。
- **取消预约**：仅在进入签到时段前允许；取消后座位立即释放，记录取消原因。
- **签到入座**：签到窗口内可签到；当前时段补约从提交时刻计算窗口。支持打开“座位签到码”，展示真实可扫描的二维码并模拟扫码签到。
- **离场签退**：使用中可主动签退，预约完成并释放座位；未签退时段结束自动完成。
- **查询个人预约、违约记录**：按状态筛选、按自习室/座位/日期搜索；展示违约次数、阈值、黑名单状态。
- **预约日历**：按月查看个人预约，支持切换月份、按日期查看当天预约，并直接签到、签退、取消或打开签到码。

### 自习室管理员模块

- **自习室房间维护**：新增、编辑、开放/停用、删除；名称唯一、开放时间合法；存在预约记录的房间禁止删除，停用仅停止新预约。
- **座位信息维护**：单座新增/编辑/启停/删除，批量按行列生成；座位编号房间内唯一；存在预约的座位禁止删除、可标记维修停用。
- **查询全部预约记录**：按日期、自习室、状态、学生/学号/编号检索；只读，学生敏感字段脱敏。
- **查询学生违约记录**：违约时间、类型、关联预约、累计次数、黑名单状态。
- **解除黑名单**：仅系统可按阈值自动加入；管理员填写解除原因与依据后解除，记录操作人、时间；历史违约记录保留。
- **预约统计报表导出**：按日期范围与自习室范围统计预约量、签到量、违约量、取消量、使用时长、座位利用率，导出 UTF-8 BOM 的 CSV（Excel 可直接打开）。

### 图书馆负责人模块

- 近 7 / 14 / 30 天使用分析：预约趋势、高峰时段、自习室利用率对比、预约状态构成、周内 × 时段热力图。
- 只展示脱敏聚合数据，不展示学生个人明细，不修改业务数据；页面标注数据更新时间与指标口径。

### 系统管理员模块

- **账号与角色权限分配**：创建账号、调整角色、启停账号、解锁；最高权限账号 `sysadmin` 不可修改或停用；不能停用当前登录账号。
- **系统操作日志查看**：按操作类型、结果、关键词筛选，分页查看，支持导出 CSV；日志只读。
- **对接校园统一身份认证**：模拟增量同步，新增/更新账号，输出异常清单；异常支持“创建账号并绑定、绑定已有账号、仅标记已处理”，处理记录留痕且再次同步不重复上报；不发起真实网络请求。
- **系统基础配置**：预约最短/最长时长、可提前天数、签到窗口、自动释放宽限、违约阈值、登录失败阈值、锁定时长、会话超时；带取值范围与参数间约束校验，变更前后值写日志。

### 系统自动处理模块

- 页面打开时每 30 秒、以及每次业务操作前扫描：签到窗口结束仍“待签到”的预约 → **已失约** + 释放座位 + 生成唯一违约记录；达到阈值 → **自动加入黑名单**。
- 使用中预约到达时段结束 → 自动完成并释放座位。
- 处理幂等：以预约 ID 作为违约唯一键，同一预约不会重复生成违约记录。
- 演示时间推进后可立即观察上述自动处理结果。

## 五、数据与权限说明

- 数据保存在浏览器 `localStorage`，键名 `jingyuan.studyroom.v1`；同一浏览器同一地址共享，不同浏览器/设备互不影响。
- 可通过“数据备份”导出/导入 JSON 文件，用于防止清缓存、换设备或误重置造成的数据丢失；导入会覆盖当前数据。
- 清除浏览器站点数据、使用无痕窗口或重置演示数据会丢失当前操作。
- 无数据库、无后端、无网络请求；页面加载的字体与图标均来自系统或内联 SVG。
- 管理员查询预约、导出报表、查看日志等操作均记录操作日志（最近保留 1500 条）。
- 无真实统一身份认证：演示账号使用固定密码，仅用于本地体验；真实部署时密码应由认证平台校验，本系统不存储认证密码。
- 管理员对预约记录为只读，符合需求规格说明书中“保障预约数据公平”的要求。

## 八、部署说明

本系统是纯静态前端，可部署到任意静态托管环境：

- 校内服务器：`node server.js`（可配合 NSSM / pm2 注册为服务，或使用 Nginx 托管目录）。
- Nginx：将本目录作为站点根目录，配置 `index.html` 即可；无需反向代理与数据库。
- 其他：GitHub Pages、内网 IIS、Apache 等静态托管均可。

部署后每个浏览器拥有自己的本地数据，不会在用户之间共享。若需要多用户共享、服务端并发控制、真实统一身份认证与长期审计，请按需求规格说明书接入后端服务与数据库，本演示的数据层可替换为 REST API。

## 九、边界与说明

- 本项目按需求规格说明书实现业务演示，不提供真实身份认证、支付、短信通知、人脸签到等扩展能力；二维码签到为本地演示，手机扫码无法跨设备读取本机 `localStorage` 数据，需点击“模拟扫码签到”写入记录。
- 二维码生成使用本地内置的 `qrcode-generator`（MIT License，版权归 Kazuhiko Arase），不发起网络请求。
- 预约时间粒度固定为所选配置的最小预约时长（默认 30 分钟）；修改最短预约时长后，界面按新粒度生成时段。
- 数据统计中的“座位利用率”口径为：有效预约时长 ÷（座位数 × 开放时长 × 统计天数），取消与失约预约不计入分子，仅统计已开放自习室。
- 所有时间均按北京时间（UTC+8）解释，与浏览器所在时区无关。
